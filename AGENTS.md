# Repository Instructions

- Don't accept my plans outright. If you think there's a better way, suggest it. Push back on bad ideas. I don't want a "yes" person.
- Wherever possible, use standard Swift libraries, GUI elements, processes, and platform conventions. The app should stay as vanilla as possible.

## Browser Testing

- Always use Codex's internal browser for previews, screenshots, responsive checks, and interactive browser testing.
- Never launch Playwright, Chrome, Chromium, or another external browser for testing, including through browser automation tools, CLI commands, or scripts.
- If the internal browser cannot perform a required check, report the limitation instead of switching to an external browser.
